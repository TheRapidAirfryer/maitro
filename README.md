# maitro! · sitio web

Página de lanzamiento de **maitro!**, la app hondureña para encontrar y cotizar maitros (pintores, albañiles, soldadores, mecánicos y más) por WhatsApp.

## Correr en tu computadora

Necesitás [Node.js](https://nodejs.org) 18 o más reciente.

```bash
npm install
npm run dev
```

Abrí el enlace que aparece en la terminal (normalmente http://localhost:5173).

## Generar la versión para publicar

```bash
npm run build
```

Los archivos quedan en la carpeta `dist/`, listos para subir a cualquier hosting (Netlify, Vercel, GitHub Pages, etc.).
